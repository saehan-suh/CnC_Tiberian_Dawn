Immediate fix required — FACING.H implicit dependency

FACING.H uses DirType (defined at line 2037 of DEFINES.H) but does not include it directly. It compiled under Watcom because every translation unit included CONQUER.H → DEFINES.H first. The GTest harness includes FACING.H in isolation — breaking that assumption.

Fix: add #include "DEFINES.H" at the top of FACING.H, below the include guard. This makes the header self-contained — a C++20 best practice.
